## Mettre à jour

- **Photo** : remplacer `profile.jpg` (utilisée pour l'aperçu LinkedIn ; la photo du site est intégrée dans index.html) (format carré, 600×600 px minimum).
- **Liens** : en haut du `<script>` dans `index.html`, bloc `CONFIG` (email, LinkedIn, GitHub).
- **Technologies de la barre défilante** : tableau `TECH` (nom, couleur du point).
- **Certifications** : tableau `CERTS`.

## Mise en ligne

1. Créer un dépôt public nommé `<nom-utilisateur>.github.io`.
2. Y déposer `index.html` et `profile.jpg`.
3. Settings → Pages → Source : branche `main`, dossier `/ (root)`.
4. Le site est en ligne sur `https://<nom-utilisateur>.github.io` après une minute ou deux.
